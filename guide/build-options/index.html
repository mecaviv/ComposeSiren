Build options

Every option is a CMake cache variable, set at configure time with -D<OPTION>=ON|OFF. The README has the details of each feature.

OptionDefaultWhat it does
PROCESS_RESOURCESONUse the resource processing outputs instead of the original resources (needs the .NET SDK)
MACOS_UNIVERSALOFFBuild a universal (x86_64 and arm64) macOS binary
COMPOSESIREN_MCPONIn-process MCP server for parameters, MIDI, and standalone audio/MIDI devices (needs a Rust toolchain)
COMPOSESIREN_RUST_DSPOFFThe Rust synthesis and its variants, chosen in the settings (see DSP performance)
COMPOSESIREN_RECORDOFFRecord the audio output to FLAC or WAV (dialog, and MCP tools with COMPOSESIREN_MCP)
COMPOSESIREN_PARK_BRIDGEOFFCompile the park UDP bridge and show the "Sirenes physiques" and "ST" controls on SirenOrchestra
COMPOSESIREN_MECAVIV_BRIDGEOFFAn optional Rust backend for the park bridge, with separately supplied dependencies (needs COMPOSESIREN_PARK_BRIDGE)
COMPOSESIREN_CLICOFFClick output: a Clic stereo bus on SirenOrchestra, MIDI channel 10, with separately supplied dependencies
COMPOSESIREN_DSP_CONTROL_MIDI_INOFFExtra MIDI-in port on SirenOrchestra for DSP Control (reverb, pan, gain, master)
COMPOSESIREN_SIREN_CONTROL_MIDI_INOFFExtra MIDI-in port on SirenOrchestra for Siren Control (notes, volume, vibrato)
COMPOSESIREN_RESETALLCONTROLLERSOFFThread-safe controller reset, MIDI CC 120/123, and the MCP reset_controllers tool (experimental)
COMPOSESIREN_SONG_TITLEOFFSong title bar: show the playing song (MCP set_song_title / clear_song_title)
COMPOSESIREN_SIREN_WAVESOFFAnimated waves in SirenOrchestra's title cells (OpenGL, software fallback)
BUILD_TESTINGOFFCTest's standard switch: builds the tests, whatever else is on
