Getting started

Getting the plugins

Download the latest installer for your OS from the releases page and run it. It installs both plugins, OneSiren and SirenOrchestra, in the formats available on your platform, and the shared resource files the simulation needs.

PlatformFormats
macOSuniversal (x86_64/arm64) 64 bit VST3, Audio Unit, Standalone Application
Windowsx64 VST3, Standalone Application
LinuxVST3, LV2, Standalone Application

The plugins are currently tested on Reaper and Ableton Live.

Building from source

ComposeSiren is built with CMake, on top of the JUCE framework. You need:

  • CMake 3.22+ and a C++20 compiler;
  • the .NET SDK (8 or later, for dotnet fsi) for the resource processing step, PROCESS_RESOURCES, which is on by default. Configure with -DPROCESS_RESOURCES=OFF to build from the original files without it;
  • Ninja is recommended, but the Xcode and Visual Studio generators work on macOS and Windows;
  • NSIS for the Windows installer.

Git tips

  • Clone with --recursive to fetch the JUCE submodule, or run git submodule update --init after cloning.
  • If an IDE alters the Dependencies/JUCE submodule, reset it with git submodule deinit -f . then git submodule update --init.
