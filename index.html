ComposeSiren
a siren orchestra in your DAW

A suite of 2 audio and MIDI virtual instrument plugins that synthesize sounds of musical sirens made by Mécanique Vivante. Their physical properties and sound are simulated in real-time from actual captured data.

Get started → Download GitHub
git clone --recursive https://github.com/mecaviv/ComposeSiren.git

Two plugins

Each plugin provides a set of parameters automatable from DAW hosts and synchronized to its MIDI input and output.

OneSiren
A simple plugin with flexible MIDI routing parameters that can simulate any siren from the orchestra.
SirenOrchestra
The whole orchestra with its original fixed MIDI routing, panning and volume for each siren, an embedded reverberation module and a master volume.

From the studio to the stage

The CC and Pitchwheel messages mirror the MIDI control parameters of the real sirens.

7 MIDI sirens
Two altos (S1, S2), a bass (S3), a tenor (S4), two sopranos (S5, S6) and a piccolo (S7).
Live performance
The DAW projects can be reused to play the pieces on the orchestra, controlling the sirens from the DAW's MIDI output.
Every platform
VST3, Audio Unit and Standalone on macOS (universal), VST3 and Standalone on Windows, VST3, LV2 and Standalone on Linux.
MCP server
Each plugin instance can run an in-process MCP server, so an assistant can set parameters, send MIDI and choose devices.
Rust DSP
Optional Rust voices, one of them bit for bit the same as the C++ voice at about 0.9× its cost.
Recorder
SirenOrchestra can record its output, after the reverb, to FLAC or WAV.
